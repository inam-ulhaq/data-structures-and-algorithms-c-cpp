## Requirements

* GCC or G++
* Any C/C++ compiler
* Linux, Windows, or macOS

## Compilation

Compile a C file:

```bash
gcc filename.c -o output
./output
```

Compile a C++ file:

```bash
g++ filename.cpp -o output
./output
```
